# snc-host's live-execution boundary: what code that snc-host loads (macro
# implementations) may subclass and call. Read by the build
# (NativeBuild.sncHostBoundary) and by link-host.sh; README.md, "snc-host",
# describes them.
#
# One pattern per line after `open` or `callable`: a NIR class name, a glob
# (`*` matches any characters), or `-` and a pattern to exclude. Open types
# also need their members called, so most of them are callable too. The host
# links with stubUnlinkable: callable code that does not link throws when it
# runs (scala-native's live.HostStubs).
